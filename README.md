# David Heavern — Portfolio

A responsive personal portfolio for David Heavern, Senior Fullstack Engineer. It presents his career history, skills, education, and contact information using the existing Minimal TypeScript starter, React, Vite, and Material UI components.

## Development

Requires Node.js 22.12 or later.

```sh
npm ci
npm run dev
```

## Validation

```sh
npm run build
npm run lint
```

To preview the production build locally, run `npm run start` after building.
